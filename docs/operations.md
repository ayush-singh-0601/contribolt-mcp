# Operations and recovery

Use the same `CONTRIBOLT_DATA_DIR` for the MCP server, approval terminal, check wrapper and inspection commands. Generated client configuration uses a project-local ignored directory. The CLI default without that configuration is `~/.local/share/contribolt`. State consists of a versioned SQLite ledger, artifacts and isolated clones; do not edit approvals or execution records by hand.

| Situation                                     | Next action                                                                                                                                                                                                                                                 |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| No verified matches                           | Read counts/reasons, expand repository preferences or try later. For a relaxation, request exactly one filter with `request_approval` action `relax_filter`, inspect and confirm it in the user terminal, then rerun discovery. Policies cannot be relaxed. |
| Unknown author/policy/competing work          | Obtain authoritative evidence or skip. Missing permissions do not turn unknown data into a verified claim.                                                                                                                                                  |
| Changed issue, new comment/assignee or new PR | Inspect the new evidence. Skip the issue or explicitly resolve the changed premise before reanalysis and fresh validation.                                                                                                                                  |
| Upstream changed                              | Re-create/update the isolated workspace, inspect the new base, reproduce again, and regenerate checks/proposal/approval.                                                                                                                                    |
| Missing compiler/dependency/service           | Keep the check `UNAVAILABLE`, approve an appropriate local setup if desired, or disclose the limitation. High-risk incomplete validation blocks publication.                                                                                                |
| Test exits zero with no output                | Enable a project test reporter so execution produces verifiable evidence. A silent test is not a recorded passing test.                                                                                                                                     |
| Command timeout/cancellation                  | Inspect captured partial output, verify no process is still running, and rerun only through the approved environment. Stop sends termination and then a bounded forced kill on supported process groups.                                                    |
| Patch/log changed                             | Inspect the changed files, rerun relevant checks, record fresh execution IDs, obtain a fresh independent critique and regenerate the exact approval preview.                                                                                                |
| Fork/push forbidden                           | Keep the local patch and explain the permission or organization restriction. Do not switch identities or force-push around it.                                                                                                                              |
| Lost publication response                     | Resume and let read reconciliation locate the exact approved branch/PR. An unmatched or ambiguous result requires manual inspection. Never open a second PR to guess whether the first succeeded.                                                           |
| Reviewer request unavailable                  | Report normal project triage/CODEOWNERS and the permission limitation. Only actual API confirmation is reported as a requested review.                                                                                                                      |
| New maintainer feedback                       | Read the feedback and observed head, prepare a focused revision plan, obtain coding approval, validate the patch, then request a separate public update grant.                                                                                              |
| PR closed without merge                       | Record `closed_without_merge`; keep the actual URL and evidence. No merge claim is made.                                                                                                                                                                    |

`control_session` supports stopping, skipping, finding another, changing preferences and forgetting saved preferences. Skipped issue URLs persist for that session. `resume_session` clears cancellation and returns the next action; unfinished grants are revoked, so request fresh consent. Commands and evidence survive interruption. Recent verified webhooks invalidate approvals and stale caches, and pending deliveries retry safely.

Rate-limit errors include a retry time where supplied by the forge. The ledger remains readable offline through `get_status`, `sessions`, `status` and MCP resources. Publication always needs fresh forge access. The bounded `watch` loop stops with Ctrl-C or the session stop control and never automatically replies to feedback.

Negative incidents can be reported locally with `contribolt record-incident SESSION_ID maintainer_complaint "factual observation and source"`, using `duplicate_attempt` or `policy_violation` for those categories. These are user-reported counts with an audit note, not automatic accusations. Metadata exports/dashboard analytics include the counts separately from successful funnel stages.

For backup/restore/upgrade, follow [hosting.md](hosting.md) even when using only local state: stop all writers, preserve the entire directory, restore to an empty destination, and use matching binary/schema versions. Keep absolute workspace paths stable or recreate and revalidate them.
