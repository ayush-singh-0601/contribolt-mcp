# Changelog

## 0.1.1 — Contribution showcase

Adds the branch-and-bolt visual identity, accessible SVG workflow and recorded fixture demo, social-preview artwork, clearer installation and client configuration guides, community templates, and searchable npm metadata. Versioned public image delivery is verified during publication.

Preserves the contribution workflow and Node.js 22.13+/24+ support. CLI, MCP, HTTP metadata, generated client pins and request identification share the release version.

## 0.1.0 — ContriBolt MCP

Supports Node.js 22.13+ alongside Node.js 24+; the CLI, runtime diagnostics, package engine and release helper use the same supported range.

Rebrands the app, MCP identity, CLI, configuration, environment names, dashboard and distribution as ContriBolt. Tagline: “ContriBolt — From open issue to pull request. Your AI-powered open-source contribution agent.” Manual CI/CD is enabled for qualification and npm publication, including public installation checks on Node 22 and 24.

Implements the ContriBolt contribution workflow: three-question onboarding; diversified forge discovery; strict dated eligibility and policy evidence; host-driven repository investigation, reproduction and focused fixes; 12 native command planners and generic fallback; captured validation and independent critique; exact human-approved fork/branch/PR publication; responsible reviewer routing, monitoring and renewed revision approvals.

Adds persistent local sessions, cancellation/resume, caching, historical heuristics, advisory similarity, trusted user adapters, GitLab/Forgejo adapters, organization acceptance manifests, signed opt-in maintainer webhooks, authenticated metadata synchronization, a read-only dashboard and optional hosting assets.

Includes client configuration for Codex, Claude Code and Cursor, pinned official MCP SDK integration, runtime diagnostics, npm packaging, platform/browser/container qualification, adversarial/recovery tests, operating/security guides, six native contribution dry runs and actual command execution for all 12 built-in adapters. The release report separates automated evidence from remaining user/live-service qualification.

Adds an authenticated npm release workflow with exact-commit CI gating, clean builds, validated tarball publication and a fresh public-registry installation checked against the archive's SHA-512 integrity.
